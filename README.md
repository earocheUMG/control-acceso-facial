# Sistema de Control de Acceso Facial

Prototipo académico de control de acceso mediante reconocimiento facial con MobileFaceNet.

## Tecnologías previstas

- Python
- OpenCV
- MobileFaceNet
- FastAPI
- PostgreSQL
- React
